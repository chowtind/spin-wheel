spin-wheel.js

Zero-dependency canvas wheel spinner. Crypto-fair, result-first picking; composite-only rotation; zero idle CPU. Source & docs on GitHub

Full layout (wheel + entries editor + history)

Everything wired: add/remove entries, shuffle, sort, eliminate mode, sound, shareable links (the wheel travels inside the URL hash), fullscreen, results log. Press Space or click the wheel.

new SpinWheel('#demo-full', {
  entries: ['Alice', 'Bob', 'Carol', 'Dave', 'Eve', 'Frank'],
  eliminate: false,
});

Wheel-only layout, driven by API

No built-in editor — you own the entry list and call the API. Winner is reported via onSpinEnd.

const wheel = new SpinWheel('#demo-bare', {
  layout: 'wheel',
  entries: myEntries,
  onSpinEnd: ({ index, name }) => showResult(name),
});
Used in production on spinwheelofnames.app (name picker, 34 languages) and wheelpick.io (wheel & random-picker tools). MIT licensed.
